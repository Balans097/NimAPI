# arithmetics — справочник модуля

> **Импорт:** отдельный `import` не нужен — все процедуры и операторы этого модуля являются частью `system` и доступны в любом файле Nim без объявления импорта.
> **Область применения:** базовая арифметика языка: порядковые операции (succ/pred/inc/dec), знаковые и беззнаковые целочисленные операторы, деление и остаток, побитовые операции и сдвиги, составные операторы присваивания, арифметика с плавающей точкой и отдельная группа "циклических" (wrap-around) операций, которые никогда не поднимают исключение переполнения.

Почти все процедуры модуля объявлены с прагмой `{.magic: "...".}` — это значит, что реальная реализация встроена прямо в компилятор (кодогенератор подставляет машинную инструкцию), а тело `proc`, если оно есть, служит только для документации и `runnableExamples`. Общая конвенция модуля: у знаковых целых чисел операции `+`, `-`, `*`, `div`, `mod`, `inc`, `dec`, `succ`, `pred` при выходе результата за диапазон типа поднимают `OverflowDefect` (или дают ошибку компиляции для констант), тогда как беззнаковые (`uint`) версии тех же операций и отдельная группа операторов с `%` в имени (`+%`, `-%`, `*%`, `/%`, `%%`) реализуют модульную (циклическую) арифметику и никогда не поднимают исключение переполнения.

## I. Порядковая арифметика: succ, pred, inc, dec

### 1. `succ`

```nim
proc succ*[T: Ordinal, V: SomeInteger](x: T, y: V = 1): T
```

**Что делает.** Возвращает `y`-го последователя значения `x` в его порядковом типе (по умолчанию — следующее значение, `y = 1`). Работает для любого `Ordinal`-типа: целых чисел, `char`, `bool`, `enum`. Если результат выходит за верхнюю границу диапазона типа (например, `succ(high(int8))`), поднимается `OverflowDefect`; для константных выражений компилятор выдаёт ошибку ещё на этапе компиляции.

**Разбор реализации.** Процедура помечена `{.magic: "Succ".}` — реальный код генерируется компилятором напрямую в машинную инструкцию сложения с проверкой переполнения, тело на Nim используется только для документации.

**Список параметров:**
- `x: T` — неизменяемое исходное значение любого порядкового типа.
- `y: V` — сколько шагов вперёд сделать, по умолчанию `1`; может быть отрицательным, тогда `succ` фактически действует как `pred`.

**Примеры:**

```nim
assert succ(5) == 6
assert succ(5, 3) == 8
assert succ('a') == 'b'
doAssertRaises(OverflowDefect):
  discard succ(high(int8))
```

---

### 2. `pred`

```nim
proc pred*[T: Ordinal, V: SomeInteger](x: T, y: V = 1): T
```

**Что делает.** Возвращает `y`-го предшественника значения `x` (по умолчанию — предыдущее значение). Симметричен `succ`: выход за нижнюю границу диапазона типа поднимает `OverflowDefect`.

**Разбор реализации.** Также `{.magic: "Pred".}` — прямая машинная инструкция вычитания с проверкой переполнения.

**Список параметров:**
- `x: T` — исходное значение порядкового типа.
- `y: V` — сколько шагов назад сделать, по умолчанию `1`.

**Примеры:**

```nim
assert pred(5) == 4
assert pred(5, 3) == 2
doAssertRaises(OverflowDefect):
  discard pred(low(uint8))
```

---

### 3. `inc`

```nim
proc inc*[T: Ordinal, V: SomeInteger](x: var T, y: V = 1)
```

**Что делает.** Изменяющая версия `succ` — увеличивает переменную `x` на месте вместо возврата нового значения. Является короткой записью для `x = succ(x, y)`. Условия переполнения те же, что и у `succ`.

**Список параметров:**
- `x: var T` — изменяемая переменная порядкового типа.
- `y: V` — величина приращения, по умолчанию `1`.

**Примеры:**

```nim
var i = 2
inc(i)
assert i == 3
inc(i, 3)
assert i == 6
```

---

### 4. `dec`

```nim
proc dec*[T: Ordinal, V: SomeInteger](x: var T, y: V = 1)
```

**Что делает.** Изменяющая версия `pred` — уменьшает переменную `x` на месте. Короткая запись для `x = pred(x, y)`.

**Список параметров:**
- `x: var T` — изменяемая переменная порядкового типа.
- `y: V` — величина уменьшения, по умолчанию `1`.

**Примеры:**

```nim
var i = 2
dec(i)
assert i == 1
dec(i, 3)
assert i == -2
```

## II. Знаковые арифметические операторы для целых чисел

Эта группа охватывает `int`, `int8`, `int16`, `int32`, `int64` — для каждого оператора существует отдельная перегрузка на каждый из этих пяти типов, все они реализуют одну и ту же семантику и в примерах ниже показаны на типе `int`.

### 1. `+` (унарный)

```nim
proc `+`*(x: int): int
```

**Что делает.** Унарный плюс, не меняет значение — существует только для симметрии с унарным минусом и для явного указания знака в выражениях вроде `+5`.

**Примеры:**

```nim
assert +5 == 5
assert `+`(-5) == -5
```

---

### 2. `-` (унарный)

```nim
proc `-`*(x: int): int
```

**Что делает.** Меняет знак `x` на противоположный. Граничный случай: для `int64` унарный минус имеет отдельную перегрузку с магией `"UnaryMinusI64"`, поскольку `-low(int64)` не помещается в `int64` и должен поднимать `OverflowDefect`, а не молча переполняться.

**Примеры:**

```nim
assert -5 == 0 - 5
assert -(-5) == 5
doAssertRaises(OverflowDefect):
  discard -low(int64)
```

---

### 3. `+` (бинарный)

```nim
proc `+`*(x, y: int): int
```

**Что делает.** Складывает два целых числа. При выходе суммы за диапазон типа поднимает `OverflowDefect`.

**Примеры:**

```nim
assert 2 + 3 == 5
doAssertRaises(OverflowDefect):
  discard high(int8) + 1'i8
```

---

### 4. `-` (бинарный)

```nim
proc `-`*(x, y: int): int
```

**Что делает.** Вычитает `y` из `x`. Так же, как и сложение, поднимает `OverflowDefect` при выходе за границы типа.

**Примеры:**

```nim
assert 5 - 3 == 2
doAssertRaises(OverflowDefect):
  discard low(int8) - 1'i8
```

---

### 5. `*` (бинарный)

```nim
proc `*`*(x, y: int): int
```

**Что делает.** Перемножает два целых числа с той же проверкой переполнения.

**Примеры:**

```nim
assert 3 * 4 == 12
doAssertRaises(OverflowDefect):
  discard high(int32) * 2'i32
```

---

### 6. `div`

```nim
proc `div`*(x, y: int): int
```

**Что делает.** Целочисленное деление с усечением к нулю (truncating division) — результат всегда округляется в сторону нуля, а не вниз. Это отличает `div` от `floorDiv` из модуля `math`. Деление на `0` поднимает `DivByZeroDefect`.

**Разбор реализации.** Примерный аналог — `math.trunc(x / y).int`, но без промежуточного перехода через числа с плавающей точкой и без потери точности на больших значениях.

**Примеры:**

```nim
assert (1 div 2) == 0
assert (7 div 3) == 2
assert (-7 div 3) == -2
assert (7 div -3) == -2
assert (-7 div -3) == 2
doAssertRaises(DivByZeroDefect):
  discard 7 div 0
```

---

### 7. `mod`

```nim
proc `mod`*(x, y: int): int
```

**Что делает.** Остаток от целочисленного деления, согласованный с `div` тождеством `x == (x div y) * y + (x mod y)`. Знак результата всегда совпадает со знаком `x` (в отличие от математического остатка по модулю, где знак совпадает с `y`). Деление на `0` поднимает `DivByZeroDefect`.

**Примеры:**

```nim
assert (7 mod 5) == 2
assert (-7 mod 5) == -2
assert (7 mod -5) == 2
assert (-7 mod -5) == -2
doAssertRaises(DivByZeroDefect):
  discard 7 mod 0
```

## III. Арифметика для беззнаковых целых чисел

### 1. `+`, `-`, `*` для uint

```nim
proc `+`*(x, y: uint): uint
proc `-`*(x, y: uint): uint
proc `*`*(x, y: uint): uint
```

**Что делает.** Те же три операции, что и в разделе II, но для `uint`/`uint8`/`uint16`/`uint32`/`uint64`. Ключевое отличие от знаковых версий: беззнаковая арифметика в Nim выполняет модульное (циклическое) сложение/вычитание/умножение и никогда не поднимает `OverflowDefect` — переполнение просто "заворачивается" вокруг диапазона типа, как в языке C.

**Разбор реализации.** Магии `"AddU"`, `"SubU"`, `"MulU"` соответствуют беззнаковым машинным инструкциям процессора, у которых само понятие переполнения на уровне железа не определено — поэтому компилятор и не вставляет проверку.

**Примеры:**

```nim
assert 3'u8 + 4'u8 == 7'u8
assert 0'u8 - 1'u8 == 255'u8       # заворот вниз через границу диапазона
assert high(uint8) + 1'u8 == 0'u8 # заворот вверх через границу диапазона
```

---

### 2. `div`, `mod` для uint

```nim
proc `div`*(x, y: uint): uint
proc `mod`*(x, y: uint): uint
```

**Что делает.** Целочисленное деление и остаток для беззнаковых чисел. Поскольку оба операнда неотрицательны по определению типа, усечение к нулю и усечение вниз здесь совпадают, а знак остатка вопрос не встаёт — результат всегда неотрицателен. Деление на `0` по-прежнему поднимает `DivByZeroDefect`.

**Примеры:**

```nim
assert 7'u8 div 2'u8 == 3'u8
assert 7'u8 mod 2'u8 == 1'u8
doAssertRaises(DivByZeroDefect):
  discard 7'u8 div 0'u8
```

## IV. Битовые операции и сдвиги

### 1. `not`

```nim
proc `not`*(x: int): int
```

**Что делает.** Побитовое дополнение (инверсия всех бит) числа `x`. Существует для всех знаковых и беззнаковых целых типов. Граничный случай наглядно проявляется на маленьких типах: `not 0'u8` даёт `255`, поскольку в беззнаковом байте все биты становятся единицами, тогда как `not 0'i8` даёт `-1`, потому что тот же битовый узор `0b1111_1111` в дополнительном коде знакового типа читается как минус один.

**Примеры:**

```nim
assert not 0'u8 == 255
assert not 0'i8 == -1
assert not 1000'u16 == 64535
assert not 1000'i16 == -1001
```

---

### 2. `and`

```nim
proc `and`*(x, y: int): int
```

**Что делает.** Побитовое "И": в результирующем числе бит установлен только там, где он установлен одновременно и в `x`, и в `y`. Часто используется как маска для извлечения нужных бит или проверки чётности (см. раздел "Практические рецепты").

**Примеры:**

```nim
assert (0b0011 and 0b0101) == 0b0001
assert (0b0111 and 0b1100) == 0b0100
```

---

### 3. `or`

```nim
proc `or`*(x, y: int): int
```

**Что делает.** Побитовое "ИЛИ": бит установлен, если он установлен хотя бы в одном из операндов. Типично используется для установки флагов в битовой маске.

**Примеры:**

```nim
assert (0b0011 or 0b0101) == 0b0111
assert (0b0111 or 0b1100) == 0b1111
```

---

### 4. `xor`

```nim
proc `xor`*(x, y: int): int
```

**Что делает.** Побитовое исключающее "ИЛИ": бит установлен, если он установлен ровно в одном из операндов, но не в обоих сразу. Часто применяется для переключения (toggle) бит и для комбинирования хэш-значений.

**Примеры:**

```nim
assert (0b0011 xor 0b0101) == 0b0110
assert (0b0111 xor 0b1100) == 0b1011
```

---

### 5. `shr`

```nim
proc `shr`*(x: int, y: SomeInteger): int
```

**Что делает.** Сдвигает биты числа `x` вправо на `y` позиций. Значение `y` приводится по модулю `sizeof(x) * 8`, то есть `15'i32 shr 35` равносильно `15'i32 shr 3`. Для знаковых типов (когда не задан флаг компиляции `nimOldShiftRight`) сдвиг арифметический: освобождающиеся слева биты заполняются копией знакового бита, поэтому сдвиг отрицательного числа вправо сохраняет его знак.

**Разбор реализации.** По умолчанию `shr` для знаковых типов реализован через ту же магию `"AshrI"`, что и отдельная функция `ashr` — то есть в актуальных версиях Nim это, по сути, один и тот же машинный код. Разница лишь в том, что поведение `shr` зависит от флага компиляции `nimOldShiftRight` (при его установке `shr` возвращается к устаревшему логическому сдвигу без сохранения знака), тогда как `ashr` гарантированно арифметический независимо от флагов компиляции. Для беззнаковых типов `shr` реализован через магию `"ShrI"` — логический сдвиг с заполнением освобождающихся бит нулями, поскольку у `uint` нет знакового бита, который нужно было бы сохранять.

**Список параметров:**
- `x` — сдвигаемое значение любого целого типа со знаком или без.
- `y: SomeInteger` — количество позиций сдвига, приводится по модулю разрядности `x`.

**Примеры:**

```nim
assert 0b0001_0000'i8 shr 2 == 0b0000_0100'i8
assert 0b1000_0000'i8 shr 4 == 0b1111_1000'i8   # сохранён знаковый бит
assert -1 shr 5 == -1
assert 16 shr 2 == 4
```

---

### 6. `shl`

```nim
proc `shl`*(x: int, y: SomeInteger): int
```

**Что делает.** Сдвигает биты числа `x` влево на `y` позиций, освобождающиеся справа биты заполняются нулями. Значение `y`, как и у `shr`, приводится по модулю `sizeof(x) * 8`. Одинаково работает для знаковых и беззнаковых типов, поскольку заполнение нулями справа не связано со знаком числа.

**Примеры:**

```nim
assert 1'i32 shl 4 == 0x0000_0010
assert 1'i64 shl 4 == 0x0000_0000_0000_0010
```

---

### 7. `ashr`

```nim
proc ashr*(x: int, y: SomeInteger): int
```

**Что делает.** Явный арифметический сдвиг вправо: освобождающиеся слева биты всегда заполняются копией знакового (самого старшего) бита, независимо от флагов компиляции. В отличие от `shr`, это не оператор, а обычная процедура, поэтому вызывается только через обычный вызов функции, а не через инфиксную запись.

**Разбор реализации.** Использует ту же магию `"AshrI"`, что и `shr` по умолчанию — `ashr` существует для того, чтобы явно зафиксировать арифметическую семантику сдвига там, где важна независимость от флага `nimOldShiftRight`.

**Примеры:**

```nim
assert ashr(0b0001_0000'i8, 2) == 0b0000_0100'i8
assert ashr(0b1000_0000'i8, 8) == 0b1000_0000'i8
assert ashr(0b1000_0000'i8, 1) == 0b1100_0000'i8
```

## V. Составные операторы присваивания для целых

### 1. `+=`

```nim
proc `+=`*[T: SomeInteger](x: var T, y: T)
```

**Что делает.** Увеличивает `x` на `y` на месте — краткая запись для `x = x + y`, с теми же условиями переполнения, что и у бинарного `+`.

**Разбор реализации.** Реализован через ту же магию `"Inc"`, что и процедура `inc` — компилятор подставляет одну и ту же машинную операцию сложения с проверкой переполнения.

**Примеры:**

```nim
var a = 5
a += 3
assert a == 8
```

---

### 2. `-=`

```nim
proc `-=`*[T: SomeInteger](x: var T, y: T)
```

**Что делает.** Уменьшает `x` на `y` на месте — краткая запись для `x = x - y`.

**Примеры:**

```nim
var a = 5
a -= 3
assert a == 2
```

---

### 3. `*=`

```nim
proc `*=`*[T: SomeInteger](x: var T, y: T) {.inline.} =
  x = x * y
```

**Что делает.** Умножает `x` на `y` на месте.

**Разбор реализации.** В отличие от `+=`/`-=`, здесь нет отдельной магии компилятора — процедура помечена только `{.inline.}` и буквально состоит из тела `x = x * y`, то есть переиспользует уже проверенный на переполнение оператор `*`. Показательно, что в модуле нет процедуры `/=` для целых чисел вообще: оператор `/` для целых типов не определён (он существует только для чисел с плавающей точкой), поэтому деление с присваиванием для целых нужно писать явно через `div`: `x = x div y`.

**Примеры:**

```nim
var a = 5
a *= 3
assert a == 15
```

---

## VI. Арифметика с плавающей точкой

Все процедуры этого раздела существуют в двух перегрузках — для `float32` и для `float`/`float64` — и, в отличие от целочисленной арифметики, никогда не поднимают `OverflowDefect`: при выходе за диапазон результат становится `Inf`/`-Inf`, а неопределённые операции вроде `0.0 / 0.0` дают `NaN`.

### 1. Унарные `+` и `-`

```nim
proc `+`*(x: float): float
proc `-`*(x: float): float
```

**Что делает.** Унарный плюс не меняет значение, унарный минус меняет знак числа с плавающей точкой, включая корректную обработку `+0.0`/`-0.0` и бесконечностей.

**Примеры:**

```nim
assert +3.5 == 3.5
assert -3.5 == 0.0 - 3.5
```

---

### 2. Бинарные `+`, `-`, `*`, `/`

```nim
proc `+`*(x, y: float): float
proc `-`*(x, y: float): float
proc `*`*(x, y: float): float
proc `/`*(x, y: float): float
```

**Что делает.** Стандартные операции с плавающей точкой по стандарту IEEE 754. Деление на `0.0` не поднимает исключение (в отличие от целочисленного `div`), а даёт `Inf`, `-Inf` или `NaN` в зависимости от знака и значения делимого.

**Примеры:**

```nim
assert 2.5 + 1.5 == 4.0
assert 5.0 / 2.0 == 2.5
assert 1.0 / 0.0 == Inf
```

---

### 3. `+=`, `-=`, `*=`, `/=`

```nim
proc `+=`*[T: float|float32|float64](x: var T, y: T) {.inline.} =
  x = x + y
proc `-=`*[T: float|float32|float64](x: var T, y: T) {.inline.} =
  x = x - y
proc `*=`*[T: float|float32|float64](x: var T, y: T) {.inline.} =
  x = x * y
proc `/=`*(x: var float64, y: float64) {.inline.} =
  x = x / y
```

**Что делает.** Составные операторы присваивания для чисел с плавающей точкой — краткая запись для `x = x + y` и аналогичных. В отличие от целочисленных `+=`/`-=`, здесь все четыре оператора реализованы единообразно: как `{.inline.}` процедуры с телом `x = x op y`, без отдельной магии компилятора, поскольку для чисел с плавающей точкой не нужна проверка переполнения.

**Примеры:**

```nim
var price = 10.0
price *= 1.2
assert price == 12.0
price /= 4.0
assert price == 3.0
```

## VII. Циклическая (wrap-around) арифметика

Все пять операторов этого раздела трактуют операнды как беззнаковые числа независимо от их фактического знакового типа, выполняют модульную операцию и никогда не поднимают исключение переполнения — результат всегда усечён (truncated) до разрядности типа. Это удобно для хэш-функций, генераторов псевдослучайных чисел и низкоуровневого кода, где переполнение — ожидаемая часть алгоритма, а не ошибка.

### 1. `+%`

```nim
proc `+%`*(x, y: int): int {.inline.} =
  cast[int](cast[uint](x) + cast[uint](y))
```

**Что делает.** Складывает `x` и `y`, как если бы оба были беззнаковыми числами, и возвращает результат обратно как знаковое число того же размера — без риска `OverflowDefect`.

**Разбор реализации.** Реализация — это дословно "приведи к uint, сложи по модулю разрядности, приведи обратно" — три операции `cast`, каждая из которых не меняет битовое представление числа, а лишь переинтерпретирует его.

**Примеры:**

```nim
assert high(int8) +% 1'i8 == low(int8)  # заворот через границу диапазона
```

---

### 2. `-%`

```nim
proc `-%`*(x, y: int): int {.inline.} =
  cast[int](cast[uint](x) - cast[uint](y))
```

**Что делает.** Вычитает `y` из `x` по тем же беззнаковым модульным правилам, что и `+%`.

**Примеры:**

```nim
assert low(int8) -% 1'i8 == high(int8)  # заворот через границу диапазона
```

---

### 3. `*%`

```nim
proc `*%`*(x, y: int): int {.inline.} =
  cast[int](cast[uint](x) * cast[uint](y))
```

**Что делает.** Перемножает `x` и `y` по беззнаковым модульным правилам.

**Примеры:**

```nim
assert 200'i8 *% 2'i8 == cast[int8](cast[uint8](200'i8) * cast[uint8](2'i8))
```

---

### 4. `/%`

```nim
proc `/%`*(x, y: int): int {.inline.} =
  cast[int](cast[uint](x) div cast[uint](y))
```

**Что делает.** Целочисленное деление, трактующее оба операнда как беззнаковые числа. Полезно, если в знаковой переменной хранится битовый узор, который логически должен интерпретироваться как беззнаковый (например, значение, полученное из сетевого протокола).

**Примеры:**

```nim
assert (-2) /% 2 == cast[int](high(uint) div 2'u + 1'u)
```

---

### 5. `%%`

```nim
proc `%%`*(x, y: int): int {.inline.} =
  cast[int](cast[uint](x) mod cast[uint](y))
```

**Что делает.** Остаток от деления, трактующий оба операнда как беззнаковые числа — беззнаковый аналог `/%`.

**Примеры:**

```nim
assert 10 %% 3 == 10 mod 3   # для неотрицательных чисел совпадает с обычным mod
```

## VIII. Практические рецепты

### 1. Циклический планировщик задач (round-robin)

```nim
type
  Scheduler = object
    tasks: seq[string]
    current: int

proc next(s: var Scheduler): string =
  ## Возвращает следующую задачу и переводит указатель по кругу.
  result = s.tasks[s.current]
  s.current = (s.current + 1) mod len(s.tasks)

var sched = Scheduler(tasks: @["A", "B", "C"], current: 0)
echo next(sched)  # выводит "A"
echo next(sched)  # выводит "B"
echo next(sched)  # выводит "C"
echo next(sched)  # выводит "A" — mod вернул указатель на начало
```

proc isEven(x: int): bool =

assert isEven(4) == true
assert isEven(7) == false

### 3. Насыщающий (saturating) счётчик

```nim
proc incSaturating(x: var int8, step: int8) =
  ## Увеличивает x на step, но останавливается на high(int8) вместо
  ## поднятия OverflowDefect — типичная задача для игровых счётчиков здоровья.
  try:
    inc(x, step)
  except OverflowDefect:
    x = high(int8)

var health = 120'i8
incSaturating(health, 20'i8)
echo health  # выводит 127 — насыщение вместо ошибки
```

  ## Комбинирует два хэша через xor и умножение с заворотом,

## IX. Краткая таблица

| Задача | Изменяет аргумент | Что использовать |
|---|---|---|
| Получить следующее/предыдущее значение | нет | `succ`, `pred` |
| Увеличить/уменьшить переменную на месте | да | `inc`, `dec`, `+=`, `-=` |
| Сложить/вычесть/перемножить целые со знаком (с проверкой переполнения) | нет | `+`, `-`, `*` |
| Сложить/вычесть/перемножить без исключений при переполнении | нет | `+%`, `-%`, `*%` |
| Целочисленное деление с усечением к нулю | нет | `div` |
| Остаток от деления со знаком, совпадающим с делимым | нет | `mod` |
| Деление/остаток, трактующие числа как беззнаковые | нет | `/%`, `%%` |
| Проверить/установить/снять один или несколько бит | нет | `and`, `or`, `xor`, `not` |
| Сдвинуть биты влево | нет | `shl` |
| Сдвинуть биты вправо с сохранением знака | нет | `shr` (по умолчанию), `ashr` |
| Сдвинуть биты вправо для беззнаковых чисел | нет | `shr` для `uint` |
| Арифметика с плавающей точкой | нет | `+`, `-`, `*`, `/` для `float` |
| Составное присваивание для чисел с плавающей точкой | да | `+=`, `-=`, `*=`, `/=` |

## X. Сводка: какую процедуру выбрать

- Нужно узнать соседнее значение порядкового типа, не трогая переменную → используйте `succ`/`pred`.
- Нужно изменить переменную на месте на шаг вперёд/назад → используйте `inc`/`dec`.
- Нужно сложение/вычитание/умножение целых чисел с гарантией, что ошибка переполнения не останется незамеченной → используйте обычные `+`, `-`, `*`.
- Нужна арифметика, где переполнение — ожидаемое поведение (хэши, генераторы, работа с сырыми битами) → используйте `+%`, `-%`, `*%`, `/%`, `%%`.
- Нужно целочисленное деление, округлённое к нулю → используйте `div`; нужен согласованный с ним остаток → используйте `mod`.
- Нужно трактовать значение как беззнаковое при делении/остатке независимо от объявленного типа → используйте `/%`/`%%`.
- Нужно работать с отдельными битами (маски, флаги, инверсия) → используйте `and`, `or`, `xor`, `not`.
- Нужен сдвиг влево → `shl`; нужен сдвиг вправо с сохранением знака независимо от флагов компиляции → `ashr`; нужен обычный оператор сдвига вправо → `shr`.
- Нужна арифметика с плавающей точкой → используйте `+`, `-`, `*`, `/` для `float`/`float32`, а для присваивания на месте — `+=`, `-=`, `*=`, `/=`.
- Нужно составное присваивание для целых, но именно деление — помните, что `/=` для целых не существует, пишите `x = x div y` явно.
