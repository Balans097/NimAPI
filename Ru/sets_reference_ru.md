# sets — справочник модуля

> **Импорт:** `import std/sets`
> **Область применения:** эффективные хеш-множества (`HashSet`) и упорядоченные хеш-множества (`OrderedSet`) — хранение уникальных значений, проверка принадлежности, теоретико-множественные операции (объединение, пересечение, разность).

Модуль `sets` реализует два типа контейнеров, хранящих только уникальные значения любого типа, для которого определена функция `hash`. `HashSet` не гарантирует порядок элементов и оптимален по скорости; `OrderedSet` дополнительно запоминает порядок вставки ценой чуть большего расхода памяти и O(n) на удаление. Общая конвенция модуля: пары процедур "изменяющая на месте / возвращающая новое значение" (например, `incl`/`union`, `excl`/`difference`), а также набор оператор-алиасов (`+`, `*`, `-`, `-+-`) для теоретико-множественных функций. Оба типа имеют *значимую семантику* — присваивание `=` копирует всё множество целиком.

## I. Типы и общие сведения

### `HashSet[A]`

```nim
type
  HashSet*[A] = object
```

**Функция.** Основной тип модуля — неупорядоченное множество уникальных значений типа `A`. Внутри хранится один плоский `seq` пар "хеш-код + ключ"; порядок обхода при итерации определяется исключительно расположением элементов внутри этого внутреннего массива и не связан с порядком добавления.

**Разбор реализации.** `HashSet` устроен как открытая адресация с линейным пробированием: каждый слот внутреннего `seq` либо пуст, либо хранит пару `(hcode, key)`. Благодаря этому вставка и поиск в среднем занимают O(1), но при вырождении (много коллизий) деградируют до O(n). Поле `counter` хранит текущее число элементов отдельно, чтобы `len` не пересчитывал занятые слоты каждый раз.

- **Параметры типа:**
  - `A` — тип элементов множества; должен поддерживать `hash(x: A): Hash` и `==`.

**Пример:**

```nim
var s: HashSet[int]  # с версии Nim 0.20 явная инициализация не нужна
incl(s, 5)
echo len(s)  # выводит 1
```

---

### `OrderedSet[A]`

```nim
type
  OrderedSet*[A] = object
```

**Функция.** Вариант хеш-множества, который дополнительно запоминает порядок вставки элементов — при итерации (`items`, `pairs`) элементы возвращаются именно в том порядке, в котором были включены.

**Разбор реализации.** Каждый слот внутреннего массива хранит не только `(hcode, key)`, но и индекс `next` — указатель на следующий по порядку вставки занятый слот. Поля `first`/`last` хранят индексы головы и хвоста этого связного списка. За счёт этого удаление элемента (`excl`) требует прохода по списку для восстановления связности — отсюда сложность O(n), в отличие от в среднем O(1) у обычного `HashSet`.

- **Параметры типа:**
  - `A` — тип элементов множества; требования те же, что и для `HashSet`.

**Пример:**

```nim
var o: OrderedSet[string]
incl(o, "b")
incl(o, "a")
for x in items(o):
  echo x  # выводит сначала "b", затем "a" — порядок вставки сохранён
```

---

### `SomeSet[A]`

```nim
type
  SomeSet*[A] = HashSet[A] | OrderedSet[A]
```

**Функция.** Объединение типов, позволяющее писать обобщённый код, работающий одинаково и с `HashSet`, и с `OrderedSet` (используется внутри модуля в реализации общих шаблонов).

- **Параметры типа:**
  - `A` — тип элементов, общий для обоих вариантов множества.

## II. Создание и инициализация

### `init` (вариант A — HashSet)

```nim
proc init*[A](s: var HashSet[A], initialSize = defaultInitialSize)
```

**Функция.** Инициализирует хеш-множество `s`, приводя его в пустое состояние. Начиная с Nim 0.20 вызывать явно не обязательно — переменная типа `HashSet[A]` уже готова к работе после объявления. Вызов на уже заполненном множестве отбрасывает все его значения — это может быть удобнее, чем вручную перебирать элементы и вызывать `excl` для каждого.

**Разбор реализации.** `initialSize` определяет начальный размер внутреннего `seq`; он округляется вверх до ближайшей степени двойки (это нужно, чтобы индекс слота можно было вычислять через побитовое `and`, а не через деление по модулю — так поиск слота дешевле).

- **Параметры:**
  - `s: var HashSet[A]` — множество, которое инициализируется (изменяемое).
  - `initialSize: int` — ожидаемый начальный размер, по умолчанию `defaultInitialSize` (64).

**Пример:**

```nim
var a: HashSet[int]
init(a)  # необязательно, но допустимо — приводит a к пустому состоянию
echo len(a)  # выводит 0
```

---

### `init` (вариант B — OrderedSet)

```nim
proc init*[A](s: var OrderedSet[A], initialSize = defaultInitialSize)
```

**Функция.** Аналог предыдущей процедуры для `OrderedSet` — приводит множество в пустое состояние и сбрасывает служебные указатели `first`/`last`.

- **Параметры:**
  - `s: var OrderedSet[A]` — инициализируемое множество.
  - `initialSize: int` — ожидаемый начальный размер, по умолчанию 64.

**Пример:**

```nim
var a: OrderedSet[int]
init(a)
echo len(a)  # выводит 0
```

---

### `initHashSet`

```nim
proc initHashSet*[A](initialSize = defaultInitialSize): HashSet[A]
```

**Функция.** Обёртка вокруг `init`, возвращающая пустое хеш-множество как значение — удобно для однострочного объявления в `var`/`let`. Как и `init`, с версии 0.20 не обязательна, но остаётся идиоматичным способом создать множество "на лету".

- **Параметры:**
  - `initialSize: int` — ожидаемый начальный размер, по умолчанию 64.

**Пример:**

```nim
var a = initHashSet[int]()
incl(a, 3)
assert len(a) == 1
```

---

### `initOrderedSet`

```nim
proc initOrderedSet*[A](initialSize = defaultInitialSize): OrderedSet[A]
```

**Функция.** Аналог `initHashSet` для упорядоченного множества.

- **Параметры:**
  - `initialSize: int` — ожидаемый начальный размер, по умолчанию 64.

**Пример:**

```nim
var a = initOrderedSet[int]()
incl(a, 3)
assert len(a) == 1
```

---

### `toHashSet`

```nim
proc toHashSet*[A](keys: openArray[A]): HashSet[A]
```

**Функция.** Строит новое хеш-множество из содержимого коллекции `keys` (массив, `seq` или строка), автоматически убирая дубликаты. Порядок элементов в результирующем множестве не определён.

- **Параметры:**
  - `keys: openArray[A]` — исходная коллекция, неизменяемая.

**Пример:**

```nim
let
  a = toHashSet([5, 3, 2])
  b = toHashSet("abracadabra")
assert len(a) == 3   # a == {2, 3, 5}
assert len(b) == 5   # b == {'a', 'b', 'c', 'd', 'r'}
```

Граничный случай — пустая коллекция:

```nim
let empty = toHashSet(newSeq[int]())
assert len(empty) == 0
```

---

### `toOrderedSet`

```nim
proc toOrderedSet*[A](keys: openArray[A]): OrderedSet[A]
```

**Функция.** Строит упорядоченное множество из коллекции `keys`, убирая дубликаты и сохраняя порядок первого появления каждого значения. В отличие от `toHashSet`, порядок обхода результата предсказуем и совпадает с порядком первых вхождений.

- **Параметры:**
  - `keys: openArray[A]` — исходная коллекция.

**Пример:**

```nim
let
  a = toOrderedSet([5, 3, 2])
  b = toOrderedSet("abracadabra")
assert len(a) == 3   # a == {5, 3, 2} — порядок первых вхождений
assert len(b) == 5   # b == {'a', 'b', 'r', 'c', 'd'}
```

## III. Проверка принадлежности и размер

### `contains` (вариант A — HashSet)

```nim
proc contains*[A](s: HashSet[A], key: A): bool
```

**Функция.** Возвращает `true`, если `key` присутствует в `s`. Эта процедура даёт возможность использовать оператор `in`/`notin`.

- **Параметры:**
  - `s: HashSet[A]` — множество, неизменяемое.
  - `key: A` — значение, наличие которого проверяется.

**Пример:**

```nim
var values = initHashSet[int]()
assert(not contains(values, 2))
assert 2 notin values

incl(values, 2)
assert contains(values, 2)
assert 2 in values
```

---

### `contains` (вариант B — OrderedSet)

```nim
proc contains*[A](s: OrderedSet[A], key: A): bool
```

**Функция.** Аналог предыдущей процедуры для `OrderedSet` — сама проверка принадлежности не зависит от порядка вставки и работает так же быстро, как и у `HashSet`.

- **Параметры:**
  - `s: OrderedSet[A]` — множество.
  - `key: A` — искомое значение.

**Пример:**

```nim
var values = initOrderedSet[int]()
assert(not contains(values, 2))
incl(values, 2)
assert 2 in values
```

---

### `` `[]` ``

```nim
proc `[]`*[A](s: var HashSet[A], key: A): var A
```

**Функция.** Возвращает не сам аргумент `key`, а тот экземпляр значения, который фактически хранится внутри множества `s` и равен `key`. Полезно, когда `hash`/`==` переопределены так, что "равные" значения могут при этом различаться по другим полям, а нужен доступ именно к хранимому в множестве экземпляру (ссылочная семантика поверх значений). Если `key` не найден, поднимается `KeyError`.

**Разбор реализации.** Процедура использует `rawGet` — внутренний поиск слота по хеш-коду и сравнению ключей; если слот найден (`index >= 0`), возвращается ссылка на хранимый там ключ, что и позволяет модифицировать его поля напрямую.

- **Параметры:**
  - `s: var HashSet[A]` — множество, изменяемое (потому что возвращается изменяемая ссылка на внутреннее хранилище).
  - `key: A` — значение, эквивалент которого разыскивается в множестве.

**Пример:**

```nim
type Person = object
  name: string
  visits: int

var people = initHashSet[Person]()
incl(people, Person(name: "Ann", visits: 0))
# получаем ссылку на хранимый экземпляр и меняем его "неключевое" поле
`[]`(people, Person(name: "Ann"))[].visits.inc
```

Ошибочный случай — обращение к отсутствующему ключу:

```nim
var s = initHashSet[int]()
doAssertRaises(KeyError):
  discard `[]`(s, 42)
```

### `len`

```nim
proc len*[A](s: HashSet[A]): int
```

**Функция.** Возвращает количество элементов в `s`. Процедуру можно безопасно вызывать даже для ещё не инициализированной переменной — в этом случае она вернёт 0. Для `OrderedSet` действует одноимённая процедура с тем же поведением.

- **Параметры:**
  - `s: HashSet[A]` (или `OrderedSet[A]`) — множество, неизменяемое.

**Пример:**

```nim
var a: HashSet[string]
assert len(a) == 0          # граничный случай — неинициализированное множество
let s = toHashSet([3, 5, 7])
assert len(s) == 3
```

---

### `card`

```nim
proc card*[A](s: HashSet[A]): int
```

**Функция.** Синоним `len` — название отсылает к математическому термину "мощность множества" (cardinality). Присутствует и для `HashSet`, и для `OrderedSet`; по смыслу и результату полностью совпадает с `len`.

- **Параметры:**
  - `s: HashSet[A]` (или `OrderedSet[A]`) — множество.

**Пример:**

```nim
let s = toHashSet([1, 2, 3])
assert card(s) == len(s)
```

## IV. Добавление элементов

### `incl` (элемент, HashSet)

```nim
proc incl*[A](s: var HashSet[A], key: A)
```

**Функция.** Добавляет `key` в множество `s`. Если `key` уже присутствует, ничего не происходит — повторное включение не создаёт дубликата и не является ошибкой.

- **Параметры:**
  - `s: var HashSet[A]` — множество, изменяемое.
  - `key: A` — добавляемое значение.

**Пример:**

```nim
var values = initHashSet[int]()
incl(values, 2)
incl(values, 2)  # граничный случай — повторное включение не увеличивает размер
assert len(values) == 1
```

---

### `incl` (элемент, OrderedSet)

```nim
proc incl*[A](s: var OrderedSet[A], key: A)
```

**Функция.** Аналог предыдущей процедуры для упорядоченного множества: новый элемент дописывается в конец порядка вставки, повторное включение существующего элемента не меняет ни множество, ни его порядок.

- **Параметры:**
  - `s: var OrderedSet[A]` — множество.
  - `key: A` — добавляемое значение.

**Пример:**

```nim
var values = initOrderedSet[int]()
incl(values, 2)
incl(values, 2)
assert len(values) == 1
```

---

### `incl` (множество в HashSet)

```nim
proc incl*[A](s: var HashSet[A], other: HashSet[A])
```

**Функция.** Добавляет в `s` все элементы множества `other`. Это версия объединения "на месте" — эквивалент `s = s + other`, но без создания промежуточной копии всего результата.

**Разбор реализации.** Реализация — простой цикл `for item in other: incl(s, item)`, то есть сложность O(m), где m — размер `other`, при условии, что вставка в среднем O(1).

- **Параметры:**
  - `s: var HashSet[A]` — множество, которое расширяется.
  - `other: HashSet[A]` — источник добавляемых элементов, неизменяемый.

**Пример:**

```nim
var
  values = toHashSet([1, 2, 3])
  others = toHashSet([3, 4, 5])
incl(values, others)
assert len(values) == 5  # значение 3 не задублировалось
```

---

### `incl` (OrderedSet в HashSet)

```nim
proc incl*[A](s: var HashSet[A], other: OrderedSet[A])
```

**Функция.** Добавляет в обычное хеш-множество `s` все элементы из упорядоченного множества `other`. Позволяет смешивать оба варианта множеств в одном выражении — например, собрать обычное множество из нескольких упорядоченных источников.

- **Параметры:**
  - `s: var HashSet[A]` — множество-приёмник.
  - `other: OrderedSet[A]` — источник элементов.

**Пример:**

```nim
var
  values = toHashSet([1, 2, 3])
  others = toOrderedSet([3, 4, 5])
incl(values, others)
assert len(values) == 5
```

---

### `containsOrIncl`

```nim
proc containsOrIncl*[A](s: var HashSet[A], key: A): bool
proc containsOrIncl*[A](s: var OrderedSet[A], key: A): bool
```

**Функция.** Одновременно проверяет и добавляет: включает `key` в множество и возвращает, содержало ли множество этот элемент *до* вызова. В отличие от `incl`, позволяет одним вызовом узнать, был ли элемент новым, без отдельного `contains` перед вставкой (что избавляет от двойного поиска слота).

- **Параметры:**
  - `s: var HashSet[A]` (или `var OrderedSet[A]`) — множество, изменяемое.
  - `key: A` — проверяемое и добавляемое значение.
- **Возвращает:** `true`, если `key` уже был в множестве; `false`, если добавлен впервые.

**Пример:**

```nim
var values = initHashSet[int]()
assert containsOrIncl(values, 2) == false  # добавлен впервые
assert containsOrIncl(values, 2) == true   # уже был в множестве
assert containsOrIncl(values, 3) == false
```

## V. Удаление элементов

### `excl` (элемент, HashSet)

```nim
proc excl*[A](s: var HashSet[A], key: A)
```

**Функция.** Удаляет `key` из множества `s`. Если `key` в множестве не найден, ничего не происходит — это не ошибка.

- **Параметры:**
  - `s: var HashSet[A]` — множество, изменяемое.
  - `key: A` — удаляемое значение.

**Пример:**

```nim
var s = toHashSet([2, 3, 6, 7])
excl(s, 2)
excl(s, 2)  # граничный случай — повторное удаление отсутствующего элемента безопасно
assert len(s) == 3
```

---

### `excl` (элемент, OrderedSet)

```nim
proc excl*[A](s: var OrderedSet[A], key: A)
```

**Функция.** Аналог предыдущей процедуры для `OrderedSet`. Эффективность — O(n), потому что для сохранения корректности связного списка порядка вставки требуется пройти по нему и "перецепить" соседние элементы удаляемого узла.

- **Параметры:**
  - `s: var OrderedSet[A]` — множество.
  - `key: A` — удаляемое значение.

**Пример:**

```nim
var s = toOrderedSet([2, 3, 6, 7])
excl(s, 2)
excl(s, 2)
assert len(s) == 3
```

---

### `excl` (множество из HashSet)

```nim
proc excl*[A](s: var HashSet[A], other: HashSet[A])
```

**Функция.** Удаляет из `s` все элементы, присутствующие в `other`. Это версия разности "на месте" — эквивалент `s = s - other`.

- **Параметры:**
  - `s: var HashSet[A]` — множество, из которого удаляются элементы.
  - `other: HashSet[A]` — множество удаляемых значений.

**Пример:**

```nim
var
  numbers = toHashSet([1, 2, 3, 4, 5])
  even = toHashSet([2, 4, 6, 8])
excl(numbers, even)
assert len(numbers) == 3  # numbers == {1, 3, 5}
```

---

### `missingOrExcl`

```nim
proc missingOrExcl*[A](s: var HashSet[A], key: A): bool
proc missingOrExcl*[A](s: var OrderedSet[A], key: A): bool
```

**Функция.** Зеркальная пара к `containsOrIncl`: удаляет `key` из множества и сообщает, отсутствовал ли он *до* вызова. Полезна, когда важно знать, было ли удаление "настоящим" (элемент реально был) или холостым.

- **Параметры:**
  - `s: var HashSet[A]` (или `var OrderedSet[A]`) — множество.
  - `key: A` — удаляемое значение.
- **Возвращает:** `true`, если `key` отсутствовал в `s` (удалять было нечего); `false`, если элемент реально был удалён.

**Пример:**

```nim
var s = toHashSet([2, 3, 6, 7])
assert missingOrExcl(s, 4) == true   # 4 и не было в множестве
assert missingOrExcl(s, 6) == false  # 6 реально удалили
assert missingOrExcl(s, 6) == true   # повторное удаление — уже отсутствует
```

---

### `pop`

```nim
proc pop*[A](s: var HashSet[A]): A
```

**Функция.** Удаляет из множества и возвращает один произвольный элемент. Какой именно элемент будет возвращён — не специфицировано (зависит от внутреннего расположения слотов). Если множество пусто, поднимается `KeyError`.

- **Параметры:**
  - `s: var HashSet[A]` — множество, изменяемое.

**Пример:**

```nim
var s = toHashSet([2, 1])
assert [pop(s), pop(s)] in [[1, 2], [2, 1]]  # порядок не гарантирован
```

Ошибочный случай:

```nim
var empty = initHashSet[int]()
doAssertRaises(KeyError):
  discard pop(empty)
```

---

### `clear`

```nim
proc clear*[A](s: var HashSet[A])
proc clear*[A](s: var OrderedSet[A])
```

**Функция.** Приводит множество к пустому состоянию, не освобождая уже выделенную под него память — последующие вставки в то же множество будут дешевле, чем в свежесозданное с нуля. Операция O(n), где n — размер внутреннего хранилища (не только занятых слотов).

- **Параметры:**
  - `s: var HashSet[A]` (или `var OrderedSet[A]`) — множество, изменяемое.

**Пример:**

```nim
var s = toHashSet([3, 5, 7])
clear(s)
assert len(s) == 0
```

## VI. Теоретико-множественные операции

Все процедуры этого раздела работают только с `HashSet` и не изменяют исходные множества — каждая возвращает новый результат.

### `union` / `` `+` ``

```nim
proc union*[A](s1, s2: HashSet[A]): HashSet[A]
proc `+`*[A](s1, s2: HashSet[A]): HashSet[A]
```

**Функция.** Возвращает объединение `s1` и `s2` — множество всех объектов, входящих хотя бы в одно из двух множеств (математически *A ∪ B*). Оператор `+` — точный алиас для `union`.

- **Параметры:**
  - `s1, s2: HashSet[A]` — исходные множества, неизменяемые.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
  c = union(a, b)
assert c == toHashSet(["a", "b", "c"])
```

---

### `intersection` / `` `*` ``

```nim
proc intersection*[A](s1, s2: HashSet[A]): HashSet[A]
proc `*`*[A](s1, s2: HashSet[A]): HashSet[A]
```

**Функция.** Возвращает пересечение `s1` и `s2` — множество объектов, входящих в оба множества одновременно (*A ∩ B*).

**Разбор реализации.** Реализация всегда перебирает элементы *меньшего* из двух множеств и проверяет их принадлежность большему — так суммарная стоимость минимальна, ведь принадлежность проверяется в среднем за O(1), а перебор меньшего множества короче.

- **Параметры:**
  - `s1, s2: HashSet[A]` — исходные множества.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
  c = intersection(a, b)
assert c == toHashSet(["b"])
```

---

### `difference` / `` `-` ``

```nim
proc difference*[A](s1, s2: HashSet[A]): HashSet[A]
proc `-`*[A](s1, s2: HashSet[A]): HashSet[A]
```

**Функция.** Возвращает разность `s1` и `s2` — элементы, входящие в `s1`, но не входящие в `s2` (*A ∖ B*). Обратите внимание, что операция несимметрична: `difference(a, b)` и `difference(b, a)` в общем случае дают разные результаты.

- **Параметры:**
  - `s1, s2: HashSet[A]` — исходные множества.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
  c = difference(a, b)
assert c == toHashSet(["a"])
```

---

### `symmetricDifference` / `` `-+-` ``

```nim
proc symmetricDifference*[A](s1, s2: HashSet[A]): HashSet[A]
proc `-+-`*[A](s1, s2: HashSet[A]): HashSet[A]
```

**Функция.** Возвращает симметрическую разность — элементы, входящие ровно в одно из двух множеств, но не в оба сразу (*A △ B*). В отличие от `difference`, эта операция симметрична: `symmetricDifference(a, b) == symmetricDifference(b, a)`.

**Разбор реализации.** Реализация начинает с копии `s1`, а затем для каждого элемента `s2` использует `containsOrIncl`: если элемент уже был (значит, он входил в оба множества), его тут же исключают через `excl` — таким образом достигается результат за один проход по `s2` без построения промежуточного пересечения.

- **Параметры:**
  - `s1, s2: HashSet[A]` — исходные множества.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
  c = symmetricDifference(a, b)
assert c == toHashSet(["a", "c"])
```

---

### `disjoint`

```nim
proc disjoint*[A](s1, s2: HashSet[A]): bool
```

**Функция.** Возвращает `true`, если у `s1` и `s2` нет ни одного общего элемента.

- **Параметры:**
  - `s1, s2: HashSet[A]` — сравниваемые множества.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
assert disjoint(a, b) == false
assert disjoint(a, difference(b, a)) == true
```

## VII. Отношения между множествами

### `` `<` ``

```nim
proc `<`*[A](s, t: HashSet[A]): bool
```

**Функция.** Возвращает `true`, если `s` является строгим (собственным) подмножеством `t` — то есть все элементы `s` входят в `t`, но в `t` есть ещё и другие элементы, которых нет в `s`.

- **Параметры:**
  - `s, t: HashSet[A]` — сравниваемые множества.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
  c = intersection(a, b)
assert c < a and c < b
assert(not (a < a))  # граничный случай — множество не строгое подмножество самого себя
```

---

### `` `<=` ``

```nim
proc `<=`*[A](s, t: HashSet[A]): bool
```

**Функция.** Возвращает `true`, если `s` является подмножеством `t` — все элементы `s` входят в `t`; при этом `s` и `t` могут быть равны.

- **Параметры:**
  - `s, t: HashSet[A]` — сравниваемые множества.

**Пример:**

```nim
let
  a = toHashSet(["a", "b"])
  b = toHashSet(["b", "c"])
  c = intersection(a, b)
assert c <= a and c <= b
assert a <= a  # граничный случай — множество является подмножеством себя
```

---

### `` `==` `` (HashSet)

```nim
proc `==`*[A](s, t: HashSet[A]): bool
```

**Функция.** Возвращает `true`, если `s` и `t` содержат одни и те же элементы (то есть являются взаимными подмножествами и имеют одинаковый размер). Порядок внутреннего расположения элементов на равенство не влияет.

- **Параметры:**
  - `s, t: HashSet[A]` — сравниваемые множества.

**Пример:**

```nim
var
  a = toHashSet([1, 2])
  b = toHashSet([2, 1])
assert a == b  # порядок добавления не имеет значения для HashSet
```

---

### `` `==` `` (OrderedSet)

```nim
proc `==`*[A](s, t: OrderedSet[A]): bool
```

**Функция.** Возвращает `true`, если `s` и `t` содержат одни и те же элементы **в одном и том же порядке**. Это ключевое отличие от `HashSet`: два упорядоченных множества с одинаковым составом, но разным порядком вставки, считаются не равными.

- **Параметры:**
  - `s, t: OrderedSet[A]` — сравниваемые множества.

**Пример:**

```nim
let
  a = toOrderedSet([1, 2])
  b = toOrderedSet([2, 1])
assert(not (a == b))  # тот же состав, но другой порядок — не равны
```

## VIII. Итерация

### `items` (HashSet)

```nim
iterator items*[A](s: HashSet[A]): A
```

**Функция.** Перебирает элементы множества `s`. Порядок обхода определяется расположением слотов внутри хранилища и не гарантирован. Если во время итерации размер множества меняется, срабатывает утверждение — модифицировать множество внутри `for` над ним нельзя.

- **Параметры:**
  - `s: HashSet[A]` — множество, неизменяемое на время обхода.

**Пример:**

```nim
var a = initHashSet[(int, int)]()
incl(a, (2, 3))
incl(a, (3, 2))
incl(a, (2, 3))  # граничный случай — дубликат не создаёт новую пару
assert len(a) == 2
```

---

### `items` (OrderedSet)

```nim
iterator items*[A](s: OrderedSet[A]): A
```

**Функция.** Перебирает элементы упорядоченного множества строго в порядке их вставки.

- **Параметры:**
  - `s: OrderedSet[A]` — множество.

**Пример:**

```nim
var a = initOrderedSet[int]()
for value in [9, 2, 1, 5, 1, 8, 4, 2]:
  incl(a, value)
for value in items(a):
  echo "Получено: ", value
# --> Получено: 9
# --> Получено: 2
# --> Получено: 1
# --> Получено: 5
# --> Получено: 8
# --> Получено: 4
```

---

### `pairs` (OrderedSet)

```nim
iterator pairs*[A](s: OrderedSet[A]): tuple[a: int, b: A]
```

**Функция.** Перебирает пары (порядковая позиция, значение) для упорядоченного множества `s` — удобно, когда важен не только элемент, но и его порядковый номер вставки.

- **Параметры:**
  - `s: OrderedSet[A]` — множество.

**Пример:**

```nim
let a = toOrderedSet("abracadabra")
var p = newSeq[(int, char)]()
for x in pairs(a):
  add(p, x)
assert p == @[(0, 'a'), (1, 'b'), (2, 'r'), (3, 'c'), (4, 'd')]
```

## IX. Преобразование и служебные процедуры

### `map`

```nim
proc map*[A, B](data: HashSet[A], op: proc (x: A): B): HashSet[B]
```

**Функция.** Строит новое множество, применяя функцию `op` к каждому элементу `data`, — удобно для преобразования типа элементов (например, чисел в строки). Обратите внимание: если `op` не инъективна (разные входы дают одинаковый результат), итоговое множество может оказаться меньше исходного — дубликаты результата схлопываются.

- **Параметры:**
  - `data: HashSet[A]` — исходное множество, неизменяемое.
  - `op: proc (x: A): B` — функция преобразования элемента.

**Пример:**

```nim
let
  a = toHashSet([1, 2, 3])
  b = map(a, proc (x: int): string = $x)
assert b == toHashSet(["1", "2", "3"])
```

Граничный случай — неинъективное преобразование:

```nim
let
  nums = toHashSet([1, 2, 3, 4])
  parity = map(nums, proc (x: int): bool = x mod 2 == 0)
assert len(parity) == 2  # {true, false} — результат меньше исходного множества
```

---

### `hash` (HashSet)

```nim
proc hash*[A](s: HashSet[A]): Hash
```

**Функция.** Вычисляет хеш-код всего множества — позволяет использовать `HashSet` как ключ в другом хеш-контейнере (например, в `Table` или другом `HashSet`).

**Разбор реализации.** Хеш-коды всех занятых слотов объединяются через `xor`, поэтому результат не зависит от порядка обхода — важное свойство, ведь у `HashSet` порядок и так не определён, а равные множества обязаны иметь равные хеши.

- **Параметры:**
  - `s: HashSet[A]` — множество.

**Пример:**

```nim
let
  a = toHashSet([1, 2, 3])
  b = toHashSet([3, 2, 1])
assert hash(a) == hash(b)  # равные множества дают равный хеш независимо от порядка
```

---

### `hash` (OrderedSet)

```nim
proc hash*[A](s: OrderedSet[A]): Hash
```

**Функция.** Аналог предыдущей процедуры для упорядоченного множества, с той разницей, что здесь используется побитовое комбинирование `!&`, учитывающее порядок обхода списка вставки — согласовано с тем, что `==` для `OrderedSet` тоже чувствителен к порядку.

- **Параметры:**
  - `s: OrderedSet[A]` — множество.

**Пример:**

```nim
let
  a = toOrderedSet([1, 2])
  b = toOrderedSet([2, 1])
assert hash(a) != hash(b)  # разный порядок — почти наверняка разный хеш
```

---

### `` `$` `` (HashSet)

```nim
proc `$`*[A](s: HashSet[A]): string
```

**Функция.** Преобразует множество в строку вида `{элемент1, элемент2, ...}` — в основном для логирования и отладочной печати. Не предназначена для сериализации: представление может измениться в будущих версиях, а значения-строки внутри не экранируются.

- **Параметры:**
  - `s: HashSet[A]` — множество.

**Пример:**

```nim
echo toHashSet([2, 4, 5])
# --> {2, 4, 5}
echo toHashSet(["no", "esc'aping", "is \" provided"])
# --> {no, esc'aping, is " provided}
```

---

### `` `$` `` (OrderedSet)

```nim
proc `$`*[A](s: OrderedSet[A]): string
```

**Функция.** Аналог предыдущей процедуры для упорядоченного множества; порядок элементов в строковом представлении совпадает с порядком вставки.

- **Параметры:**
  - `s: OrderedSet[A]` — множество.

**Пример:**

```nim
echo toOrderedSet([2, 4, 5])
# --> {2, 4, 5}
```

## XI. Практические рецепты

### 1. Удаление дубликатов из последовательности

```nim
proc uniqueValues[A](xs: openArray[A]): seq[A] =
  ## Убирает повторяющиеся значения, сохраняя порядок первого появления.
  let seen = toOrderedSet(xs)  # OrderedSet хранит первые вхождения по порядку
  result = newSeq[A]()
  for x in items(seen):
    add(result, x)

echo uniqueValues([3, 1, 3, 2, 1, 4])  # выводит @[3, 1, 2, 4]
```

---

### 2. Поиск общих элементов в нескольких коллекциях

```nim
proc commonToAll[A](groups: seq[seq[A]]): HashSet[A] =
  ## Находит элементы, присутствующие сразу во всех группах.
  if len(groups) == 0:
    return initHashSet[A]()
  result = toHashSet(groups[0])
  for i in 1 ..< len(groups):
    result = intersection(result, toHashSet(groups[i]))

let
  team1 = @["Ann", "Bob", "Carl"]
  team2 = @["Bob", "Carl", "Dan"]
  team3 = @["Carl", "Bob"]
echo commonToAll(@[team1, team2, team3])  # выводит {Bob, Carl} (порядок не гарантирован)
```

### 3. Отслеживание уже обработанных элементов (кэш посещений)

```nim
proc processOnce[A](items: openArray[A], visited: var HashSet[A]) =
  ## Обрабатывает только те элементы, которых ещё не было в `visited`.
  for item in items:
    if not containsOrIncl(visited, item):
      echo "Обрабатываю: ", item
    # если containsOrIncl вернул true — элемент уже встречался, пропускаем

var seen = initHashSet[int]()
processOnce([1, 2, 2, 3, 1], seen)
# --> Обрабатываю: 1
# --> Обрабатываю: 2
# --> Обрабатываю: 3
```

### 4. Сравнение двух версий конфигурации

```nim
proc diffConfigs(old, new: openArray[string]): tuple[added, removed: HashSet[string]] =
  ## Показывает, какие ключи появились, а какие пропали между двумя версиями.
  let
    oldSet = toHashSet(old)
    newSet = toHashSet(new)
  result.added = difference(newSet, oldSet)
  result.removed = difference(oldSet, newSet)

let (added, removed) = diffConfigs(
  ["timeout", "retries", "host"],
  ["timeout", "host", "max_connections"])
echo "Добавлено: ", added    # --> {retries} нет, --> {max_connections}
echo "Удалено: ", removed    # --> {retries}
```

### 5. Планировщик с сохранением порядка постановки в очередь

```nim
proc scheduleTasks(order: var OrderedSet[string], task: string) =
  ## Добавляет задачу в очередь, если её там ещё нет — порядок постановки сохраняется.
  incl(order, task)

proc runNext(order: var OrderedSet[string]): string =
  ## Забирает первую по порядку постановки задачу и убирает её из очереди.
  for t in items(order):
    result = t
    excl(order, t)
    return result
  raise newException(ValueError, "очередь пуста")

var queue = initOrderedSet[string]()
scheduleTasks(queue, "build")
scheduleTasks(queue, "test")
scheduleTasks(queue, "build")  # дубликат — очередь не меняется
echo runNext(queue)  # выводит "build"
echo runNext(queue)  # выводит "test"
```

## XIII. Сводка: какую процедуру выбрать

- Нужно быстро убрать дубликаты и порядок неважен → `toHashSet`.
- Нужно убрать дубликаты, но важен порядок первого появления → `toOrderedSet`.
- Нужно просто проверить "есть ли элемент" → `contains` или оператор `in`.
- Нужно добавить элемент и одновременно узнать, был ли он новым → `containsOrIncl`, а не `incl` + отдельный `contains`.
- Нужно удалить элемент и узнать, было ли что удалять → `missingOrExcl`, а не `excl` + отдельный `contains`.
- Нужно достать "любой" элемент и сразу убрать его из множества → `pop`.
- Нужно объединить/пересечь/вычесть множества, не трогая исходные → `union`/`intersection`/`difference`/`symmetricDifference` (или операторы `+`/`*`/`-`/`-+-`).
- Нужно то же самое, но изменить одно из множеств на месте → `incl(s, other)` вместо `+`, `excl(s, other)` вместо `-`.
- Нужно проверить, что два множества не имеют общих элементов → `disjoint`.
- Нужно сравнить множества по составу, порядок вставки неважен → `HashSet` и его `==`.
- Нужно сравнить множества и по составу, и по порядку вставки → `OrderedSet` и его `==`.
- Нужно преобразовать тип элементов множества → `map`.
- Нужно использовать множество как ключ другого контейнера → `hash` уже определён для обоих типов, отдельно вызывать не нужно.
- Встретили `initSet`, `toSet` или `isValid` в старом коде → замените на `initHashSet`, `toHashSet` и уберите вызов `isValid` вовсе — с версии 0.20 он не нужен.
